# AGENTS.md — conventional-changelog-action

> GitHub Action that bumps version, generates a changelog via Conventional Commits, and tags a release commit — used as shared CI/CD tooling across Clearcover repos.

## Quick start

```bash
# Install
npm ci

# Build — compiles src/ + all presets into dist/ (must be committed)
npm run build

# Tests run only via GitHub Actions (no local test script)
# See .github/workflows/test.yml for test jobs
```
